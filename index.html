MediAssist Launcher

Start once, open everything from here.

Run npm run dev in this folder, then use this page as your launchpad for the patient kiosk, staff desk, vitals desk, and doctor panel. The backend and voice transcription flow will work through the same startup command.

Frontend served from this folder
Backend expected on localhost:5000
Voice transcription runs through the backend
P
Patient

Patient Check-In

Open the kiosk form and voice intake flow for new patient registration.
S
Staff

Staff Dashboard

Review patient details, save notes, and manage the registration handoff.
V
Vitals

Vitals Desk

Load the patient by token and capture blood pressure, heart rate, temperature, and SpO2.
D
Doctor

Doctor Panel

Open the consultation view, review the active case, and prepare the prescription output.

Tip: once npm run dev is running, open the printed Home link in your browser and keep it bookmarked.
